# FileScanner

Утилита для многопоточного сканирования файлов в директории на наличие сигнатур (подозрительных последовательностей/паттернов) с логированием результатов.

## Архитектура

Проект реализован по классической схеме producer-consumer:

* **Scanner** — точка входа логики сканирования. Рекурсивно обходит указанную директорию, формирует задачи и передает их в очередь.
* **SafeQueue** — потокобезопасная очередь задач, синхронизирующая продюсера и пул воркеров.
* **ThreadPool** — пул рабочих потоков. Забирает задачи из очереди, вычитывает файлы чанками и проверяет содержимое на совпадение с сигнатурами.
* **Details / Logger** — модуль разбора базы сигнатур (CSV) и потокобезопасной записи результатов в лог-файл (`report.log`) и консоль.

Потоки работают параллельно, благодаря чему сканирование больших каталогов и тяжелых файлов не упирается в последовательный I/O.

## Сборка

```bash
mkdir build && cd build
cmake ..
cmake --build .
```

Для сборки с тестами:

```bash
cmake -DBUILD_TESTS=ON ..
cmake --build .
```

## Использование

```bash
./file_scanner <путь_к_директории> <база_сигнатур.csv>
```

- `<путь_к_директории>` — папка с файлами для анализа.
- `<база_сигнатур.csv>` — CSV-файл с известными сигнатурами для поиска.

Результаты сканирования выводятся в консоль и записываются в `report.log`.

## Тестирование

Сгенерировать тестовые файлы и запустить тесты:

```bash
# генерация тестового набора файлов
python3 tests/generate_files.py

# запуск тестов из директории build
ctest --output-on-failure
# или напрямую бинарником:
./tests/scanner_tests

```
